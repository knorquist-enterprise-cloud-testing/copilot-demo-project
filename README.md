# Copilot Demo Project

A multi-language demonstration project used for Copilot usage metrics and PR analysis.

## Languages

- **TypeScript** — API server and utilities
- **Python** — Analytics and data processing
- **Go** — High-performance backend services

## Structure

```
src/           # TypeScript source
python/        # Python analytics
go/            # Go services
scripts/       # Bash automation
```

## Getting Started

```bash
npm install
npm run dev
```
